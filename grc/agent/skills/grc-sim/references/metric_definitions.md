# 指标定义

## EVM(Error Vector Magnitude,误差矢量幅度)
- 定义:接收符号与理想星座点的欧氏距离,相对参考幅度归一,通常以 % 表示。
- 越小越好;噪声越大 / 频偏越大 -> EVM 越高。
- 计算需知调制方式(bpsk/qpsk)与每符号样本数 sps(用于符号定时抽取)。

## BER(Bit Error Rate,误比特率)
- 定义:错误比特数 / 总比特数。需要已知发送比特作参考。
- 教学链路里通常用随机源 + 已知种子,或用 EVM 作近似质量代理。

## 星座图(constellation)
- 与 EVM 同一套符号：RRC 匹配滤波后按 sps 搜最佳相位再散点。不要对未同步的过采样 IQ 直接抽样。

## 频谱(spectrum)
- Hann 窗 + FFT shift，纵轴 dBFS。若 0 Hz 相对邻域高 6 dB 以上，视为直流尖峰并从主峰中排除。

## 眼图(eye)
- 按符号周期叠绘时域波形;眼睛张开度反映码间串扰与噪声裕度。
